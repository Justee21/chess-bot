# Baseline results: harness vs plain Maia 3

Run 2026-11-02/03. Model `maia3-23m`, Maia Elo input **1700** (calibrated), sampling temperature **1.0** (tuned).
Data: 10,040 standard-chess games for Justin0921. Train = oldest 85% (8,534 games), test = newest 15% (1,506 games, 53,504 of Justin's moves). The table, Elo calibration, and temperature tuning use training games only; the test set is used only for the numbers below.

## 1. Next-move accuracy on the held-out test set

Top-1 / top-3 = how often Justin's actual move is the model's most likely / one of its three most likely moves. Evaluated at temperature 1.0 so the numbers describe the model's real distribution.

|---|---|---|---|---|---|---|---|
| **All** | 53,504 | 0.587 | **0.612** | 0.850 | **0.857** | -1.267 | **-1.252** |

Where the table fires (position seen >= 3 times in training): **7,119 of 53,504 moves (13.3%)**, top1 **0.802**, top3 0.951. Elsewhere the harness is plain Maia (top1 0.583 on those 46,385 moves).

Reading: the table adds about **2.5 points** of top-1 overall and about **9 points in the opening**. Middlegame and endgame are identical by construction, so that is where any further gain would have to come from.

## 2. Game quality (Stockfish depth 12, centipawn loss)

| | Justin, train sample (300 games, 10,124 moves) = tuning target | Justin, test sample (300 games, 10,937 moves) | Bot self-play at T=1.0 (40 games, 3,710 moves) |
|---|---|---|---|
| Average centipawn loss | 68.8 | 71.4 | 65.1 |
| Moves losing > 100 cp | 18.4% | 18.7% | 17.2% |
| Moves losing > 200 cp | 9.3% | 9.9% | 8.1% |
| Moves losing > 300 cp | 5.7% | 6.3% | 5.2% |

Justin by time control (train sample): blitz 64.6, rapid 62.4, bullet 73.8 average cp loss. The test sample is more bullet-heavy (7,567 of 10,937 moves), which is why its average is higher.

Temperature sweep (average cp loss vs the train target 68.8): T=0.6 -> 55.8, T=0.8 -> 56.0, **T=1.0 -> 65.1**, T=1.2 -> 74.0. T=1.0 is closest; the bot's error profile is in the same range as Justin's, slightly cleaner than his recent (test) games.

Method note: an earlier version of this section sampled the target from all games (about 15% test games) and treated a draw that could merely be claimed next move as already drawn, which inflated centipawn loss. Both were fixed after the code review (the tuning target now uses training games only; only real draws count). The numbers above are from the corrected runs.

## 3. Opening book depth

Ply at which Justin's side first stands in a position the table does not cover (table needs count >= 3):

- Justin's test games: median **10**, mean 9.7 (n=1,506)
- Bot self-play: median **11**, mean 11.0 (n=200 sides)

The bot stays in book about one ply longer than Justin does; it is playing its own repertoire against itself rather than against Justin's real opponents.

## Caveats

- Self-play error profile uses 40 games per temperature, so it is noisy: T=0.6 and T=0.8 came out almost identical (55.8 vs 56.0) and T=1.2 (74.0) is also not far from the targets (68.8 train, 71.4 test). A finer grid (e.g. 1.0, 1.1, 1.2) with 150+ games would settle between 1.0 and about 1.1.
- Elo calibration used 150 sampled training games; the curve peaked at 1700 with an interior maximum (800-2200 scanned).
- Over half of Justin's games are bullet; the bot has no clock, so bullet time-pressure moves cannot be reproduced.
- Not measured yet: the LLM playstyle judge and the blind human test.

## Is a fine-tune worth it?

The headroom is in the middlegame and endgame (top1 0.578 in both, 70% of Justin's moves), where the harness is plain Maia. The table already handles the opening, and the bot already matches Justin's centipawn-loss profile. A fine-tune of Maia on the training games is the only lever left for those phases; whether the gain justifies it is Justin's call. If yes, it gets its own plan, and the same evaluation (`chessbot evaluate`) is the yardstick.
